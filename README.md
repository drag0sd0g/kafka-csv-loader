# kafka-csv-loader

A Kotlin CLI tool for loading CSV files into Kafka with Avro schema validation.

## Status
🚧 Under active development — initial scaffold in progress.

## Overview
This tool reads CSV files, validates rows against an Avro schema, and produces messages to Kafka topics.

### Features (planned)
- CSV parsing with schema validation
- Avro serialization with Schema Registry support
- Dry-run mode for validation only
- Error reporting and dead-letter file output
- Progress tracking and colorful CLI output
- Native binary distribution (GraalVM)
